### testng-api.xml ⚠️ ISSUE: wrong browser
```xml
<parameter name="browser" value="chromium"/>
```
- **Problem:** ConfigManager uses `"chrome"` (Playwright Chromium channel). `"chromium"` is the raw Playwright engine — different binary.  
- **Impact:** Tests in this suite launch a different browser than all other suites.  
- **Fix:** Change to `value="chrome"` — or remove the parameter and let `config.properties` default apply.  
- **Type:** Package-based (`<packages>`) — scans entire `com.toskie.tests.api` package. Fine for small packages.

## 2. PARALLEL EXECUTION AUDIT

All active suites use `parallel="none"`. This is **intentional and correct** because:
- App uses persistent WebSocket connections — parallel browser sessions conflict on the same QA account
- Profile creation wizard has sequential steps — cannot run in parallel
- OTP bypass uses shared QA phone/email — concurrent OTP requests conflict

**To enable parallelism in future:**
1. Provision separate QA accounts per thread (N accounts for N threads)
2. Move to `parallel="classes"` with `thread-count="4"` or `"8"`
3. Ensure `BrowserManager`, `ApiUtils`, and `ReportManager` ThreadLocal isolation (already implemented)
